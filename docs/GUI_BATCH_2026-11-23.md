# GUI acceptance batch — 23 November 2026

**Prepared, not executed.** Six project-owned Windows sessions, 25 pinned PR snapshots. This is a convenience batch for human GUI assessment, **not** automatic PR merging, acceptance or a shared unrelated-project Windows VM.

## Run from the existing TempToPC Linux Codespace

1. Update TempToPC with `git pull --ff-only` and use `python3 scripts/batch-windows.py list` to review the queue.
2. Each target repository needs a manual `temptopc-acceptance.yml` caller and its own `TAILSCALE_AUTHKEY` and `TEMPTOPC_RDP_PASSWORD` GitHub Actions secrets. Restrict Tailscale ACL to your authorized device on TCP 3389.
3. Run `python3 scripts/batch-windows.py preflight chromofoxEXT`; then `python3 scripts/batch-windows.py launch chromofoxEXT`. The latter requires typing LAUNCH before **one** runner is dispatched.
4. View that repository's new Actions run summary to obtain the *private* tailnet 100.x address. Connect from a tailnet-authorized Windows PC with mstsc (non-admin user `temptopc-test`).
5. Under `C:\TempToPC\Sources\PR-N` find exact-head PR source worktrees, and `C:\TempToPC\Sources\INDEX.json` their identities. Under `C:\TempToPC\Artifacts` find the selected prebuilt artifact if configured. **Nothing is auto-installed or executed.** Copy any tree into a writable user folder before changing it.
6. Install only known dependencies and evaluate one PR/stack at a time. Record `PASS`, `FAIL`, or `BLOCKED` with exact SHA, environment and screenshots inside `C:\TempToPC\Feedback`. Cancel the run after collecting evidence; the job uploads explicit feedback for seven days.
